Proyecto: Sistema de Inventario de un Minimarket

Avances realizados

1. Definición de requisitos: se identificaron las funcionalidades principales para consultar y gestionar los productos del inventario.
2. Elaboración de diagramas UML: se documentaron los modelos para representar las funcionalidades y la estructura del sistema.
3. Definición de la arquitectura: se organizó la propuesta de arquitectura y la separación de responsabilidades entre frontend y backend.
4. Organización del proyecto: se utilizaron GitHub Projects y tareas priorizadas para dar seguimiento al desarrollo.
5. Consolidación de evidencias: se incorporaron al repositorio documentos PDF, diagramas y capturas del programa.
